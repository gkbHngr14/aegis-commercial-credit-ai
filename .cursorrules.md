# Aegis Commercial Credit AI - Cursor Project Rules

- Always write modular, type-hinted Python 3.11+ code with explicit docstrings.
- Strict TDD: Every new ingestion or graph module must have corresponding pytest assertions in tests/.
- Ingestion Rules: Chunks must never split mid-sentence or truncate HTML/Markdown tables. Every Chunk object MUST contain metadata lineage tags: 'tenant_id', 'document_id', 'section_id', and 'effective_date'.
- Safety Gate Rules: The SafetyGate class must enforce a sub-150ms DeBERTa-v3 NLI entailment threshold >= 0.90 and numerical variance checks before returning a verdict. Fall back to raw RAG context if assertions fail.
- Prompt Rules: All prompt interactions must conform to schemas in prompts/v1_taxonomy.json using user_template strings with dynamic variable substitution.
